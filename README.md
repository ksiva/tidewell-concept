# Tidewell — concept brand and website

A spec / portfolio project: brand identity, website templates and campaign assets for a fictional
collection of small hotels on the Mediterranean coast. Tidewell, its hotels, prices and copy are invented.

- Live: https://ksiva.github.io/tidewell-concept/
- Brand book and campaign assets: https://ksiva.github.io/tidewell-concept/brand/
- Templates: home, filterable listing, hotel page, editorial article, paid-traffic landing page, 600 px email,
  display banners (HTML5) and paid-social formats.
- Stack: Astro 7 (content collections for hotels and stories), GSAP for motion, self-hosted OFL fonts
  (Bodoni Moda, Hanken Grotesk). Respects `prefers-reduced-motion`.
- Photography: Unsplash, Unsplash License; per-photo sources on the credits page.
